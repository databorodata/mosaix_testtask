# Поиск аналогов позиций сметы

Прототип по тестовому заданию: ввод наименования → до пяти похожих позиций из истории закупок
с объяснением совпадений и отличий, либо честное «не найдено». Устройство и схемы — в
[ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

```bash
docker compose up --build
```

Страница: http://localhost:8000. Первая сборка скачивает модели (~3,4 ГБ, образ ~7,5 ГБ),
дальше контейнер работает без сети и ключей; проверено на собранном образе. Без докера: `uv venv && uv pip install -r requirements.txt`, затем
`.venv/bin/uvicorn app.web:app --port 8000`.

Готовые данные подготовки лежат в репозитории — ключи не нужны. Повторить подготовку с нуля:
`python -m scripts.run_prep --rows data/full/rows_all.json --out data/full/prep_all.jsonl`
с ключами Yandex Cloud в `.env` (прошлый прогон занял 77 минут). Замер качества:
`python -m scripts.eval_search --set eval/final_set.json --out eval/final`. Тесты: `pytest`.
Обучение решения: `python -m scripts.train_decision`.

## Допущения

- База из задания считается историей закупок; цена условная и в отборе не участвует.
- Единиц измерения в базе нет — характеристики берутся из наименования.
- Строки про перевозку и погрузку оставлены в базе отдельным типом: запрос об услуге ищет только
  среди услуг, запрос о материале их не видит. Надбавки и доплаты — так же.
- Комплекты «в составе:» ищутся целиком; у заголовков без состава в выдаче пометка
  «состав в строке не расписан».
- Три правила замен в `rules/rules.yaml` — допущение; настоящие задаёт специалист заказчика.
  Словари видов и сокращений — `rules/synonyms.yaml`.
- Карточки позиций собраны заранее из наименования и открытых описаний (Yandex Search API +
  Qwen3.6-35B-A3B, логирование у провайдера выключено). Наружу уходило только наименование.
  При поиске внешних вызовов нет.
- Верные ответы контрольных наборов размечены ИИ-агентами, не видевшими кода поиска; спорные
  случаи помечены в самих наборах. Журнал всех правок и замеров: `eval/JOURNAL.md`.
- Сырые тексты веб-выдачи в репозиторий не включены (`.gitignore`): публикуются только
  производные карточки.
